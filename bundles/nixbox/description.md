# BundleDock nixbox

The glibc companion of the BundleDock toolbox: a glibc runner, the glibc
release binaries and distribution tools in Nix store layout, published as a
multi-architecture OCI image (linux/amd64 and linux/arm64). Use it beside the
[toolbox](https://quay.io/repository/bundledock/toolbox), which holds the
statically linked and portable tools.

- Documentation: https://wstein.github.io/bundledock/
- Source and issues: https://github.com/wstein/bundledock
