# BundleDock agy

The official prebuilt Antigravity CLI (`agy`), published as a multi-architecture
OCI image (linux/amd64 and linux/arm64). The bundle carries the vendor's
executable unmodified. Mount it as a read-only tool volume at `/opt/bdock/agy`.
Authentication and configuration stay with the consumer; see the documentation.

- Documentation: https://wstein.github.io/bundledock/
- Source and issues: https://github.com/wstein/bundledock
